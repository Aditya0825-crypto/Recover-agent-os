# RecoveryOS Agent Guidelines

Guidelines for building, maintaining, and developing the RecoveryOS full-stack application.

- **Backend**: Python 3.11+, FastAPI, PostgreSQL, SQLAlchemy, Redis, Celery.
- **ML Pipeline**: Scikit-Learn, XGBoost, SHAP, Pandas, NumPy.
- **Frontend**: React, TanStack Start / Router, Tailwind CSS, Recharts.
- **Policy Engine**: Deterministic Python guardrails with bounded action set (`WAIT`, `RETRY`, `PAYMENT_LINK`, `REMINDER`, `HUMAN_REVIEW`, `STOP`).
